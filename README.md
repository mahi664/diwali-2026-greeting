# Diwali 2026 — A Festival of Light

A responsive, bilingual (English + Marathi) Diwali greeting website.

## Features
- Interactive diya and animated fireworks
- English / Marathi language toggle
- Native share sheet for WhatsApp and other apps
- Optional sound toggle
- Mobile-first static HTML/CSS/JavaScript — no build step

## Run locally
Open `index.html` in a browser.

## Deployment
GitHub Actions deploys the root directory to GitHub Pages whenever code is pushed to `main`.

After the first commit, open **Settings → Pages → Build and deployment → Source** and select **GitHub Actions**.

Expected URL: https://mahi664.github.io/diwali-2026-greeting/
